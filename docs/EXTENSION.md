# 浏览器起始页 · 0.7.0 书签辨识与设置整理

当前 Fork：[Acew-zl/RhineLabUI](https://github.com/Acew-zl/RhineLabUI)。本地 `origin` 指向此仓库，`upstream` 保留原作者仓库。

Chromium Manifest V3 新标签页扩展。保留三维出场准备、原档案阵列动效和画质，扩展内将档案映射到浏览器书签栏，新增搜索框及书脊标记。档案正面恢复原始莱茵标签与编号。普通网页仍显示原档案。

## 更新现有扩展

本机 `release/extension` 已构建为 0.7.0。在扩展管理页找到 Rhine Lab，点击「重新加载」，再新建标签页。0.7.0 沿用 0.2.0 权限；如果从 0.1.0 更新，可能需要允许书签和站点图标权限。若你之前安装的是 ZIP 解压到其他位置的副本，需要用新版包替换那个目录，或重新加载本项目的 `release/extension`。

旧警告保存在浏览器的扩展错误列表中，不会因源代码修复自动消失。清除旧日志后再新开标签页，检查是否产生新的错误。本次已将弃用的 `PCFSoftShadowMap` 改为 Three.js 实际使用的 `PCFShadowMap`，不改变已经生效的阴影类型。

## 书签和书脊

- 第一列是书签栏根部未放入文件夹的书签；后续每个顶层文件夹一列，顺序沿用浏览器。嵌套目录的书签按原顺序归入所属顶层列，详情显示完整文件夹路径。
- 空列显示「此列暂无书签」。同名文件夹增加数字后缀用于区分。每列可以超过 8 条或 32 条，刻度只显示当前附近最多 8 个位置，滚轮、上下切换继续循环。
- 「打开书签」/ Enter 默认在新标签页打开选中的书签，保留导航页与选档状态；右侧等大的「档案详情」按钮打开详情，也可鼠标双击已经选中的三维档案；单击其他档案仍只选中，拖动不会触发详情，保留 360° 模型入口。
- 「备注」是浏览器保存的书签名称，不生成额外描述。书脊的空名称保持为空；右侧正文、ARCHIVE INDEX 和搜索结果在无名称时显示网址。仅有 Logo 的书签也可正常使用。Logo 和备注位于档案顶部朝上的窄面，文字沿顶边单行排列，过长省略；竖直侧面和正面不放书签信息。界面标题悬停和详情仍可查看完整名称。
- 设置 → 书签显示中的「书脊 Logo」「书脊名称 / 备注」分别控制书脊图标和名称：两者都开、仅 Logo、仅名称或全部隐藏。默认都开，本地保存，下次新标签页继续使用。原有开关偏好继续保留；关闭两项也不会隐藏正面的原始标签。
- 设置中的 OPEN LINKS / 链接打开方式提供「新标签页（默认）」和「当前页」，统一用于书签、详情页打开入口、搜索匹配及网络搜索。选择当前页后会覆盖导航页，偏好自动保存。
- 图标使用 Chromium 的本地 `_favicon` 接口，不向第三方图标服务发送书签网址。没有可用图标时，书脊使用名称首字符占位，右侧名称旁使用通用地球图标。只有实际进入可见范围或被选中的书签才请求图标。
- 图标先读取浏览器缓存的 32px 图像；失败再尝试 16px 和站点首页缓存，解码为像素后绘入顶部纹理。设置显示读取数量和失败状态，可点「重试图标」重新尝试失败项。首字只是占位，不能视为真实 Logo；HTTP 网页预览没有图标接口，会明确提示在已安装扩展的新标签页检查。
- 读取书签，不创建、修改或删除浏览器书签。当前页检测到书签改变后提供「刷新书签」，避免突然重播或打断操作；新开的标签页直接读取最新数据。
- 顶部居中搜索框支持搜索网络或输入 HTTP(S) 网址，搜索引擎可在设置选择 Bing、Google、百度。ARCHIVE INDEX 可按书签名称、网址和文件夹检索。书签脚本（`javascript:`）等可执行地址不会运行。

## 设置组织

设置依次分为「浏览与搜索」「书签显示」「启动与动效」「画面与性能」「声音」。前两组默认展开，其余按需展开；图标状态与重试收在书签显示的次级入口。

「名称旁的网站 Logo」默认开启，控制右侧选中名称左边的图标，与两个书脊开关独立保存。图标复用浏览器本地缓存，通过独立的二维画布显示，不受三维画质、景深或雾色影响。没有缓存图标时使用通用地球占位，不把首字冒充网站 Logo。底部恢复方向键切列、前后选档和 Enter 的原始按键提示。

## 布局与清晰度

- 文件夹切换位于右侧 INTERNAL DATABASE 上方，名称加大并显示与该列一致的色标；书签信息向右集中，减少重复分类与权限文字。
- 不同列有轻微的玻璃色差，同一列全部档案保持同色，选中、归位及循环副本沿用对应列的颜色。
- 桌面预览相比 0.5.0 拉开约 16% 的视野（投影尺寸约缩小 14%），选中预览抬起高度为 0.6，介于早期的 0.4 和 0.6.0 的 0.8 之间，保持左侧构图；抽取仍只竖直升降。详情回到原有放大比例。顶部渐变集中为搜索栏留白。
- 主阵列书脊使用独立的屏幕分辨率渲染层，避开三维渲染比例、景深和顶部遮罩；使用实际模型深度保持遮挡关系。背景远处的标签仍淡出，选中标签不受雾色洗白。小尺寸 favicon 的原始像素上限依然存在，不能凭空补出细节。

## 启动方式

设置中的 STARTUP / 启动方式提供三项，下次新标签页生效，不改变「减少动态效果」。

- 完整启动动画：默认保留原流程及有声点击入口。
- 简短动画 · 就绪即进入：自动播放开头约 1.2 秒以上，模型、字体和三维预热完成后立即进入阵列；慢加载继续播放前段并在三维出现前等待。
- 直接进入三维档案：自动启动，加载时只显示准备提示，完成后进入三维阵列，不播放片头。

自动进入遵守浏览器声音策略，第一次鼠标/键盘交互后才启用声音，原音量及开关偏好不变。主动点击 REINITIALIZE 仍完整重播，不被短启动设置截断。失败沿用重新连接入口。

## 搜索操作

搜索栏位于页面上方正中间并加宽，复用档案检索的放大镜、MiSans 字体、直角细线和明暗配色；聚焦时底线展开，减少动态效果时直接显示。不会自动抢占浏览器地址栏焦点。

- 阵列界面按 `/` 聚焦搜索栏。原 ARCHIVE INDEX 按钮仍打开完整档案索引；详情界面的 `/` 继续打开索引。
- 输入关键词后直接按 Enter，或点击右侧箭头，使用当前引擎搜索网络。输入 HTTP(S) 网址则直接打开；不带协议的域名默认 HTTPS。本机 HTTP 服务须写 `http://`。
- 搜索栏右上可选择 Bing、Google、百度，与设置中的搜索引擎同步，本地保存。
- 输入时同时查找书签名称、网址和文件夹路径，支持多个词，完整名称及前缀匹配优先。最多显示五条本地匹配；上下键选择，Enter 打开选中的书签，也可直接点击结果。
- Esc 依次收起列表、清空内容、退出输入；× 一键清空。中文组词期间不执行提交。输入与方向键不会同时触发三维选档。
- 搜索文字不持久化、不请求远程联想；仅主动提交网络搜索时才将关键词交给选定引擎。打开书签或网址遵循 OPEN LINKS 设置，默认新标签页。

## 安装验收

1. 在项目目录执行 `npm ci`（首次安装），再执行 `npm run build:extension`。需要 Node.js 24。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择项目中的 **`release/extension`** 文件夹，即包含 `manifest.json` 的那一层。
5. 新建标签页；若浏览器询问是否保留新的新标签页，选择保留。

本机验收路径：`D:\Project\RhineLabUI\release\extension`。安装后运行不需要 Node、终端或开发服务器。也可以把整个文件夹发给别人，以同样方式加载；面向普通用户的一键安装需后续上架扩展商店。

修改源码后重新执行 `npm run build:extension`，在扩展管理页点击此扩展的「重新加载」，再新开标签页。关闭或移除此扩展即可恢复浏览器原来的新标签页。当前替换的是新标签页；启动浏览器时是否打开新标签页由浏览器的「启动时」设置决定。

## 实现边界

GLB、MiSans 字体、界面图标、音频与 TXT 资源全部随扩展打包；书签和站点图标从本机浏览器读取，不打入分发包。仅申请 `bookmarks` 和 `favicon` 权限，无远程脚本、无后台常驻进程、无站点访问权限。扩展不注册网页 PWA，也不复制其 Service Worker。独立授权的 Novecento 字体 kit 不进入扩展，使用原项目自带的固定文字图形。

字体准备好即可开始 2D 开场；模型加载及同一 WebGL 上下文的材质编译、纹理/几何上传、阴影与后期通道准备同时进行。预热不推进相机、弹簧、波浪或选档时间轴。极慢情况下停在三维出现前的覆盖帧，准备完成再继续；失败可重新连接。

首次着色器编译仍占用计算资源，预热是提前完成工作，不保证所有设备零掉帧。独立 360° 查看器仍按需创建自己的场景，本轮针对主阵列首次出场。

## 开发与检查

```sh
npm run dev:extension
npm run build:extension
npm run check:extension
npm run preview:extension
```

`dev:extension` 是带热更新的开发预览；`preview:extension` 在 `http://127.0.0.1:5190` 提供实际产物并使用相同 CSP。HTTP 页面没有书签权限；显式加 `?bookmarks-demo=1&scene=archive` 可使用样例数据，页面会标注「书签演示数据」。样例含嵌套、空文件夹和 45 条书签的列，不包含个人书签。HTTP 预览不等于真实扩展安装测试。普通网页继续使用 `npm run dev` / `npm run build`。
