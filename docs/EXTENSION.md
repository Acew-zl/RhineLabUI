## 0.8.7 变更

2026-10-02，按用户认可的 UX 前三项实现；验证与复现见 [EXTENSION-0.8.7.md](../verification/EXTENSION-0.8.7.md)。

- 书脊阅读避让：非选中阵列标签在计数、操作提示和页脚区域平滑淡出，过大的前景标签适度减淡。与既有循环和顶部淡出叠加，不缩小字体、不添加模糊；选中及归位书脊保持清晰。静区布局仅在尺寸或模式变化后更新，页脚时钟不会持续触发 WebGL 重绘。

- 后台打开：中键、Windows / Linux 的 Ctrl 点击、macOS 的 ⌘ 点击可以打开任意可点击档案及本地搜索/索引结果，保留当前页面与选中项；Mac Ctrl 不当作后台打开。明确的后台手势不受“覆盖当前页”设置影响。
- 取消切页：Esc、改选档案、打开设置/查看器、返回阵列或主动切走标签页会取消尚未完成的自动激活。已经创建的网页保留在后台，不替用户关闭。再次确认相同目标时不重复创建正在调取的标签页。
- 检索一致性：顶部与索引共用宽字符归一化、多关键词匹配和标题排序，顶部超过五条时可进入索引查看全部。“其他书签”等未显示为三维列的内容也可在索引检索，不虚构模型位置。原有文件夹左右导航保留。
- 不增加权限、访问记录或常驻后台进程；其余 UX 候选仅列于 [下一轮建议](UX-NEXT-STEPS.md)，等待用户审查。

## 0.8.6 变更

2026-09-30，按用户审查后确认的方案实现；验证与复现见 [EXTENSION-0.8.6.md](../verification/EXTENSION-0.8.6.md)。

- **没有 WebGL 也能用**：三维场景无法创建、载入或预热失败时进入 2D 界面，书签、搜索、档案索引与详情照常使用，底部提示可重试或关闭（关闭后一周内不再提示）。三维显示中途丢失且 5 秒内未恢复（例如打开过多页面被浏览器回收）同样切换到 2D。一帧出错不再让页面停止响应，本地收藏数据损坏也不会白屏。
- **启动方式**：新增并默认「每天首次完整 · 之后简短」，当天第一次打开播放完整开场，看完或跳过后，当天其余新标签页使用简短动画。已手动选过启动方式的用户保持原选择；REINITIALIZE 仍完整重播。
- **默认静音**：所有用户升级后统一静音一次，之后只在用户开启时播放。右上角「设置」左侧新增声音按钮，一键静音／恢复上次的音效与音乐组合；设置「05 / 声音」仍可分别控制。静音时完整开场无需点击「进入」即可播放。
- **静止呼吸与重绘**：「画面与性能」新增「静止呼吸」：30 秒后静止（默认）／持续起伏／关闭。静置 30 秒后起伏在数秒内平稳停下，画面不再变化，已有的静止画面复用生效，GPU 不再重绘；检测降至每秒 5 次，任何输入立即恢复。新标签页和网页不再要求高性能显卡（壁纸版不变）。画质、分辨率与光影不变。
- **网址与搜索词**：只有真实顶级域名（内置 IANA 列表）、完整 IPv4、`localhost`、IPv6 或局域网专用名称（`.local`、`.lan` 等）才按网址打开；本机和局域网地址使用 http。`node.js`、`package.json`、`3.14`、`1.5倍` 等按搜索处理。列表首行提供另一种处理方式（「打开网址」或「搜索」），按 ↓ 选择。
- **浏览器内部页面书签**：`chrome://`、`edge://`、`about:` 和本地文件书签改用浏览器标签页接口打开（无需新增权限）；本地文件需在扩展详情页开启「允许访问文件网址」，被浏览器拒绝时给出提示。
- **书签范围**：书签栏只有文件夹时不再生成空的第一列；书签栏为空时底部给出添加方法。「02 / 书签显示」新增「其他书签与移动设备书签」（默认关闭），开启并刷新后作为额外的文件夹列显示；顶部搜索始终包含这些书签。
- **跟随系统**：动态效果改为「跟随系统／始终完整／始终减少」，系统设置变化时即时生效；旧版保存的减少动态效果如与系统不同，视为明确选择保留。界面配色新增「跟随系统」，默认仍为亮色。
- **最小字号**：扩展交互界面中其余标签、页脚、详情与设置文字在小屏幕上不小于 12 显示像素（主题按钮、详情页签 14），大屏幕保持原尺寸；配色不变。窄窗口下搜索栏自动让出导航按钮的位置。
- **多个新标签页同步**：设置保存时只写入本页改动的项，并接收其他已打开页面的修改；收藏在写入前先读取最新列表。主题、声音、画质、帧率、收藏、书脊与打开方式等在各页之间即时同步。
- **大量书签**：超过 512 个书签时，书脊贴图只为画面中最近的 512 个标签分配 1024px 槽位并循环复用，贴图上限约 8192×4096；图标到达后的贴图上传合并为每秒最多 4 次。ARCHIVE INDEX 每次渲染 150 行、滚动时继续加载，书签很多时输入防抖。

## 书签和书脊

- 第一列是书签栏根部未放入文件夹的书签（书签栏只有文件夹时省略此列）；后续每个顶层文件夹一列，顺序沿用浏览器。嵌套目录的书签按原顺序归入所属顶层列，详情显示完整文件夹路径。开启「其他书签与移动设备书签」后，这两个位置的根部书签和顶层文件夹依次追加为列。
- 空列显示「此列暂无书签」。同名文件夹增加数字后缀用于区分。每列可以超过 8 条或 32 条，刻度只显示当前附近最多 8 个位置，滚轮、上下切换继续循环。
- 「打开书签」/ Enter 默认在新标签页打开选中的书签，保留导航页与选档状态；右侧等大的「档案详情」按钮打开详情，也可鼠标双击已经选中的三维档案；单击其他档案仍只选中，拖动不会触发详情，保留 360° 模型入口。
- 「备注」是浏览器保存的书签名称，不生成额外描述。书脊的空名称保持为空；右侧正文、ARCHIVE INDEX 和搜索结果在无名称时显示网址。仅有 Logo 的书签也可正常使用。Logo 和备注位于档案顶部朝上的窄面，文字沿顶边单行排列，过长省略；竖直侧面和正面不放书签信息。界面标题悬停和详情仍可查看完整名称。
- 设置 → 书签显示中的「书脊 Logo」「书脊名称 / 备注」分别控制书脊图标和名称：两者都开、仅 Logo、仅名称或全部隐藏。默认都开，本地保存，下次新标签页继续使用。原有开关偏好继续保留；关闭两项也不会隐藏正面的原始标签。
- 设置中的 OPEN LINKS / 链接打开方式提供「新标签页（默认）」和「当前页」，统一用于书签、详情页打开入口、搜索匹配及网络搜索。选择当前页后会覆盖导航页，偏好自动保存。
- 图标使用 Chromium 的本地 `_favicon` 接口，不向第三方图标服务发送书签网址。没有可用图标时，书脊使用名称首字符占位，右侧名称旁使用通用地球图标。只有实际进入可见范围或被选中的书签才请求图标。
- 图标先读取浏览器缓存的 32px 图像；失败再尝试 16px 和站点首页缓存，解码为像素后绘入顶部纹理。设置显示读取数量和失败状态，可点「重试图标」重新尝试失败项。首字只是占位，不能视为真实 Logo；HTTP 网页预览没有图标接口，会明确提示在已安装扩展的新标签页检查。
- 读取书签，不创建、修改或删除浏览器书签。当前页检测到书签改变后提供「刷新书签」，避免突然重播或打断操作；新开的标签页直接读取最新数据。
- 顶部居中搜索框支持搜索网络或输入网址，搜索引擎可在设置选择 Bing、Google、百度。ARCHIVE INDEX 可按书签名称、网址和文件夹检索。书签脚本（`javascript:`）等可执行地址不会运行；`chrome://`、`edge://`、`about:` 和本地文件书签通过浏览器标签页接口打开。

## 设置组织

设置依次分为「浏览与搜索」「书签显示」「启动与动效」「画面与性能」「声音」。前两组默认展开，其余按需展开；图标状态与重试收在书签显示的次级入口。

「名称旁的网站 Logo」默认开启，控制右侧选中名称左边的图标，与两个书脊开关独立保存。图标复用浏览器本地缓存，通过独立的二维画布显示，不受三维画质、景深或雾色影响。没有缓存图标时使用通用地球占位，不把首字冒充网站 Logo。底部恢复方向键切列、前后选档和 Enter 的原始按键提示。

| 模式 | 操作/开场上限 | 空闲上限 |
| --- | --- | --- |
| 均衡（默认） | 60 FPS | 30 FPS |
| 节能 | 30 FPS | 15 FPS |
| 跟随屏幕刷新率 | 不额外限帧 | 不额外限帧 |

连续输入、惯性拖动、选档和镜头切换保持操作帧率，交互结束约 4 秒后进入空闲帧率。实际帧率仍受显示器和设备性能限制；设置保存后即时生效。后台隐藏页面继续停止三维更新。书脊独立清晰层与主场景一起限帧，两者分辨率、模型细节、材质和光影不变。原动画按真实时间运行，不以帧数计时。验证与复现见 [NEW-TAB-PERFORMANCE.md](../verification/NEW-TAB-PERFORMANCE.md)。

## 显示名称

首次使用（包括从旧版更新）时，开场在 `ID CONFIRMED` 的用户名位置暂停。淡色 `JOYCE MOORE` 是默认提示，输入名称后按 Enter 或点击确认继续；留空确认使用默认名称。中文输入法选字时的 Enter 不会提交。最多 24 个完整字符，保留大小写、中文和 Emoji。

名称与首次确认状态保存于本机，之后新标签页和重播不再询问。简短开场、直接进入或减少动态效果的首次使用也会显示一次身份输入，确认后按所选方式进入档案，不修改启动偏好。在「设置 → 03 / 启动与动效 → 显示名称」中修改，按 Enter 或离开输入框保存；清空后确认恢复默认名称。名称用于开场、页脚、设置简介和本机读取记录，不读取浏览器账号，不新增权限。隐私说明见 [PRIVACY.md](../PRIVACY.md)，运行验证见 [USER-NAME.md](../verification/USER-NAME.md)。

## 启动方式

设置中的 STARTUP / 启动方式提供三项，下次新标签页生效，不改变「减少动态效果」。

- 每天首次完整 · 之后简短（默认）：当天第一次打开播放完整开场，看完或跳过后，当天其余新标签页使用简短动画。
- 每次完整启动动画：保留原流程；开启声音时保留有声点击入口。
- 简短动画 · 就绪即进入：自动播放开头约 1.2 秒以上，模型、字体和三维预热完成后立即进入阵列；慢加载继续播放前段并在三维出现前等待。
- 直接进入三维档案：自动启动，加载时只显示准备提示，完成后进入三维阵列，不播放片头。

声音默认关闭，静音时不显示点击入口。开启声音后，自动进入遵守浏览器声音策略，第一次鼠标/键盘交互后才启用声音。主动点击 REINITIALIZE 仍完整重播，不被短启动设置截断。失败沿用重新连接入口。

## 搜索操作

搜索栏位于页面上方正中间并加宽，复用档案检索的放大镜、MiSans 字体、直角细线和明暗配色；聚焦时底线展开，减少动态效果时直接显示。不会自动抢占浏览器地址栏焦点。

- 阵列界面按 `/` 聚焦搜索栏。原 ARCHIVE INDEX 按钮仍打开完整档案索引；详情界面的 `/` 继续打开索引。
- 输入关键词后直接按 Enter，或点击右侧箭头，使用当前引擎搜索网络。输入网址则直接打开：带 `http(s)://`、以真实顶级域名结尾（不带协议时使用 HTTPS），或是完整 IPv4、`localhost`、IPv6、`.local` 等局域网名称（使用 HTTP）。`node.js`、`3.14` 等文字按搜索处理。列表首行给出另一种处理方式，按 ↓ 后 Enter 选择。
- 搜索栏右上可选择 Bing、Google、百度，与设置中的搜索引擎同步，本地保存。
- 输入时同时查找书签名称、网址和文件夹路径，支持多个词，完整名称及前缀匹配优先。最多显示五条本地匹配；上下键选择，Enter 打开选中的书签，也可直接点击结果。
- Esc 依次收起列表、清空内容、退出输入；× 一键清空。中文组词期间不执行提交。输入与方向键不会同时触发三维选档。
- 搜索文字不持久化、不请求远程联想；仅主动提交网络搜索时才将关键词交给选定引擎。打开书签或网址遵循 OPEN LINKS 设置，默认新标签页。

## 安装验收

Edge 用户可直接从 [Microsoft Edge 扩展商店](https://microsoftedge.microsoft.com/addons/detail/ghkdoeojkoenedlobcpaaeocopddkkmp) 安装。Chrome 0.8.3 专用版已通过审核（用户确认）；其他桌面 Chromium 浏览器可使用 [GitHub 已发布完整版 ZIP（0.8.2）](https://github.com/Acew-zl/RhineLabUI/releases/tag/extension-v0.8.2)。本地 0.8.7 由 `npm run build:extension` 与 `npm run build:extension:chrome` 生成 `release/extension` 和 `release/extension-chrome`；打包为 ZIP 时 `manifest.json` 须位于根目录，解压后按以下步骤加载。Firefox 与 Safari 尚无正式发行包。

1. 在项目目录执行 `npm ci`（首次安装），再执行 `npm run build:extension`。需要 Node.js 24。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择项目中的 **`release/extension`** 文件夹，即包含 `manifest.json` 的那一层。
5. 新建标签页；若浏览器询问是否保留新的新标签页，选择保留。

本机验收路径：`D:\Project\RhineLabUI\release\extension`。安装后运行不需要 Node、终端或开发服务器。也可以把整个文件夹发给别人，以同样方式加载。Vivaldi 需在浏览器设置中允许扩展控制新标签页。

修改源码后重新执行 `npm run build:extension`，在扩展管理页点击此扩展的「重新加载」，再新开标签页。关闭或移除此扩展即可恢复浏览器原来的新标签页。当前替换的是新标签页；启动浏览器时是否打开新标签页由浏览器的「启动时」设置决定。

## 实现边界

GLB、MiSans 字体、界面图标、音频与 TXT 资源全部随扩展打包；书签和站点图标从本机浏览器读取，不打入分发包。仅申请 `bookmarks` 和 `favicon` 权限，无远程脚本、无后台常驻进程、无站点访问权限。扩展不注册网页 PWA，也不复制其 Service Worker。独立授权的 Novecento 字体 kit 不进入扩展，使用原项目自带的固定文字图形。

字体准备好即可开始 2D 开场；模型加载及同一 WebGL 上下文的材质编译、纹理/几何上传、阴影与后期通道准备同时进行。预热不推进相机、弹簧、波浪或选档时间轴。极慢情况下停在三维出现前的覆盖帧，准备完成再继续。三维无法创建或准备失败时，开场在三维出现的时间点直接进入 2D 界面。

首次着色器编译仍占用计算资源，预热是提前完成工作，不保证所有设备零掉帧。独立 360° 查看器仍按需创建自己的场景，本轮针对主阵列首次出场。
