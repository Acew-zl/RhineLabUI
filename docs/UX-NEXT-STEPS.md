# UX 审查后的下一轮候选

2026-10-02。前三项已进入 0.8.7：书脊阅读避让、确认打开后调取并切页、中键及 Ctrl/⌘ 后台打开。本页只列剩余条目中可单独成立的小改进，尚未实现，供用户审查。

| 顺序 | 精简后的改动 | 解决的问题与范围 |
| --- | --- | --- |
| 1 | 校正小窗口的初始相机构图 | 1366×768 已有验证截图中，首个选中档案的左侧被裁切。只调整响应式相机构图，保留档案尺寸、抽取规则与波浪，先提供画面对照。 |
| 2 | 准确的状态与操作文案 | 不支持的地址显示“无法直接打开”，不再显示 AUTHORIZED；扩展快捷键写“Enter 打开书签”。保持原网页档案语义。 |
| 3 | 按真实书签 ID 记住上次位置 | 保存上次选中项及各列位置；书签删除时回退到有效相邻项。不预测每日落点，不统计打开次数，不将 SAVED 改成另一种功能。需决定这是默认行为还是可选设置。 |
| 4 | 刷新后保留位置 | 首步沿用现有刷新方式但恢复选中书签及文件夹，避免每次回到第一项。原地更新目录可作为后续独立工作，需维护模型、索引、收藏和贴图的一致性。不增加入库表演、封存或随机推荐。 |
| 5 | 长名称和提示条的布局修正 | 长标题显示完整省略号，保留现有文字滚动与详情中的完整名称；2D 备用提示和书签状态避免覆盖操作提示；暗色搜索背景规则限定在弹窗，顶部栏保留原有通透感。不新增悬停提示层。 |
| 6 | 更直白的本地处理说明 | 首次命名补“仅保存在本机”；说明读取书签及浏览器缓存图标的方式，书脊与摘要统一缺失图标占位。使用普通说明，不增加封存报告、写入计数或显影动画。 |

第 6 条的改动须以实际实现为依据，不能用装饰性的“SEALED”承诺安全。日期字段仅在用户认为有用时再加入；不为填满详情而生成信息。

暂不采用：设置面板自动变淡或移动、返回页面补演动画、会话锁、访问账本、熟悉度解密、每日预测、今日重现及图形化设置仪表。引线可以保留为将来的独立视觉对照，但必须让开书脊文字，并保留已认可的右侧标题和按钮。

所有后续方案均需保留静止画布复用、后台暂停和减少动态效果设置，不引入常驻轮询或为装饰持续重绘。
